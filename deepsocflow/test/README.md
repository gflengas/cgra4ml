# deepsocflow/test Directory

This directory contains the tests for the `deepsocflow` project.

## Subdirectories

- **`py/`**: This directory likely contains Python tests, probably using a framework like `pytest`, to test the functionality of the Python code in `deepsocflow/py`.

- **`sv/`**: This directory likely contains SystemVerilog testbenches for verifying the RTL code in `deepsocflow/rtl`. These testbenches are used to simulate the hardware design and check for correctness.

- **`wave/`**: This directory is likely used to store waveform files (e.g., `.vcd`, `.wlf`) that are generated during simulation. These files can be viewed with a waveform viewer to debug the hardware design.
